📝 To-Do List Application

A simple console-based To-Do List application built with Python.
This project allows users to add, view, and remove tasks, while also saving the tasks in a text file so they remain available after restarting the program.

🚀 Features

* ➕ Add new tasks
* 👀 View all saved tasks
* ❌ Remove tasks
* 💾 Automatically save tasks in tasks.txt
* 🔄 Load previously saved tasks when the program starts
* 🚪 Exit the application

🛠️ Technologies Used

* Python
* VS Code / Terminal
* Text File (tasks.txt) for data storage

📂 Project Structure

To-Do-List/
│
├── todo.py
├── tasks.txt
└── README.md

▶️ How to Run

1. Clone this repository:

git clone <your-repository-link>

2. Open the project folder in VS Code.
3. Run the program:

python todo.py

4. Use the menu to manage your tasks.

📌 How It Works

When the program starts, it reads the existing tasks from tasks.txt.

You can then choose from:

1. Add Task
2. View Tasks
3. Remove Task
4. Exit

Whenever a task is added or removed, the tasks.txt file is updated accordingly.
